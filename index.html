升级须知

这一版需要手动安装

v1.6.1 更换了应用的签名密钥。签名一旦更换，旧版本无法自动升级到新版本——这是系统层面的限制，绕不过去。Windows 手动覆盖安装即可；Android 这一轮暂不发布。

Windows直接覆盖安装

1.6.0 及更早版本内置的是旧签名公钥，应用内「检查更新」会一直验证失败。请直接下载安装包运行。

  1. 下载 Windows 安装包
  2. 直接运行，覆盖安装即可

本地数据不受影响。装上这一版之后，后续更新恢复正常。

Android这一版暂不发布

Android 只允许同一签名的安装包覆盖安装。签名换了之后，新版无法覆盖旧版，只能卸载重装——而卸载会清空应用内的全部数据，目前应用里还没有一键备份全部数据的功能。

把用户推进这条路是不负责任的，所以 v1.6.1 不发布 Android 版。安卓端仍是 v1.6.0，可以继续正常使用，也不会收到更新提示。

下一个 Android 版本会先补上完整的数据导出与导入，再一并处理签名更换。请不要在此之前自行卸载重装。

v1.6.1 做了什么

修复启动卡死与白屏

修复了会话数据在特定情况下无限膨胀，导致启动时长时间无响应、最终白屏的问题。根因是用户头像被完整复制进了每一条消息，使单次加载超出浏览器内核对单个字符串的容量上限。

自动修复已膨胀的数据

启动时会自动清理存量数据中重复内嵌的头像，清理前自动备份整个数据库。实测一个 620 MB 的数据库清理后降至 96 MB，角色、会话、记忆、预设、世界书与附件条数完全一致。

修复数据目录指针丢失

修复了存储配置文件在编码异常时被误判为「不存在」、随后被默认路径覆盖的问题。该问题会让应用指向空目录，看起来像数据全部丢失。现在读不懂就停止启动并给出恢复方式，不再覆盖写入。

新增「设置数据路径」

可以把应用指向某个已经存在的数据目录（设置 → 存储）。此前只有「迁移」，也就是把当前数据搬到别处；重装或换机之后手上只剩一份数据目录时，反而没有入口能让应用用上它。切换只改写指针，不复制也不删除任何文件，当前数据原地保留；确认前会先显示目标目录里的角色数与会话数供核对。

新增崩溃诊断

应用启动、迁移与错误会记录到本机日志；异常退出会在下次启动时提示，并保留崩溃前的最后操作。界面出错时不再是空白窗口，而是显示错误说明与一键复制的诊断摘要。日志不含聊天内容、角色卡正文或模型密钥。

常见问题

创作应该保持简单

Character Editor 是免费的吗？＋

是。公开发行仓库提供可直接下载的桌面安装包，当前不收取费用。

我的角色和聊天数据会上传吗？＋

角色、世界书、预设和会话默认保存在本机。只有在你主动配置 AI 服务或 MCP 服务时，相关请求才会发送到对应服务。

如何获得新版本？＋

正常情况下可以在应用设置里检查更新，也可以随时回到本页面手动下载。但 v1.6.1 是例外：这一版更换了签名密钥，旧版本无法自动升级，Windows 必须按升级须知手动安装一次。装上 1.6.1 之后，后续版本恢复自动更新。

为什么这次要手动安装？＋

应用的更新包由一把私钥签名，安装后的版本用配套的公钥验证它。这一版更换了这对密钥，于是旧版本手里的公钥验不过新包，Android 系统也拒绝让签名不同的包覆盖安装。这是系统层面的安全机制，只能手动装一次。

覆盖安装会丢数据吗？＋

Windows 不会。数据保存在安装目录之外，覆盖安装不会碰它，新版本启动后继续使用同一份数据。如果你把数据放在了自定义位置而新版本没有认出来，可以在应用的设置 → 存储里用「设置数据路径」重新指向它——这个操作只改指针，不会复制或删除任何文件。

Android 为什么没有 v1.6.1？＋

因为签名换了之后新版无法覆盖安装，只能卸载重装，而卸载会清空应用内的全部数据，目前还没有一键备份全部数据的功能。与其让你冒这个险，不如先不发。安卓端停留在 v1.6.0，可以继续正常使用，也不会收到更新提示；等数据导出与导入补齐后再一并更新。
