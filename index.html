旧版 Android 的迁移说明

Android v1.6.0 及更早版本使用不同的签名，无法直接覆盖安装当前版本。卸载旧版会清空应用内数据，请先按下面的步骤导出并备份。v1.6.3 及以上版本沿用同一签名，可以直接在应用内升级。

Windows正常更新

v1.6.1 及以上：在「设置 → 软件更新」中直接升级。

v1.6.0 及更早：内置的仍是旧签名公钥，应用内「检查更新」会验证失败，请下载安装包直接运行，覆盖安装即可。

本地数据保存在安装目录之外，覆盖安装不受影响。

下载 Windows 安装包
Android仅 v1.6.0 及更早：先导出，再重装
  1. 在旧版里导出需要的数据：RP 与 AI 助手会话列表中的「备份全部」、角色卡、世界书、预设、正则、自己的 Skill，以及 AI 工作空间里的文件夹。
  2. 把导出的文件复制出来。旧版会把它们存进「内部存储/Android/data/com.character_editor.app/files/Download」，卸载时这里会被一起删除。可以用数据线连接电脑复制，也可以用手机自带的文件管理器移到「下载」文件夹（部分手机不允许访问 Android/data，这时请用电脑）。
  3. 卸载旧版，下载并安装最新版。
  4. 把文件放回手机的「下载」文件夹，先导入角色卡，再导入会话并绑定到对应的角色；世界书、预设、正则和 Skill 按原来的方式导入。

从旧签名版本重装时，AI 助手的长期记忆、模型与供应商配置（包括 API Key）、MCP 服务和偏好设置需要在新版中重新设置。

装上 v1.6.3 或更新的版本之后，Android 的后续更新可以直接覆盖安装。

v1.7.1 做了什么

助手会先检查自己的工具

CE 助手的官方预设会先查询当前可用工具，再回答能否生图或处理文件等问题；需要使用的工具会先启用。已有内置预设会补入这条规则，同时保留其他编辑。

直接用生图模型聊天

在 AI 助手中选用图像专用模型，输入文字描述即可生成图片。产物保存到文件管理器的媒体目录；普通对话回复中的图片也会尝试保存到媒体目录，方便之后查找和下载。

修复图片下载

图片查看器通过应用读取远程图片，修复部分图片下载或复制时出现的 Failed to fetch。远程地址无法读取时，原链接仍会保留，并提示保存失败。

会话标题更贴近内容

新会话默认以首条用户文字命名，也可以在模型设置中开启 AI 标题，由指定的标题模型生成。手动改名不会被 AI 覆盖。

错误提示回到对话末尾

AI 助手生成出错时，错误提示显示在所属轮次的最后一条消息之后。

常见问题

创作应该保持简单

Character Editor 是免费的吗？＋

是。公开发行仓库提供可直接下载的桌面安装包，当前不收取费用。

我的角色和聊天数据会上传吗？＋

角色、世界书、预设和会话默认保存在本机。只有在你主动配置 AI 服务或 MCP 服务时，相关请求才会发送到对应服务。

如何获得新版本？＋

正常情况下可以在应用设置里检查更新，也可以随时回到本页面手动下载。例外有两种：Windows v1.6.0 及更早需要手动安装一次；Android v1.6.0 及更早需要按升级须知导出数据后重装。之后两端都恢复应用内更新。

为什么需要手动安装或重装？＋

应用的更新包由一把私钥签名，安装后的版本用配套的公钥验证它。v1.6.1 起更换了这对密钥，于是旧版本手里的公钥验不过新包，Android 系统也拒绝让签名不同的包覆盖安装。这是系统层面的安全机制，只能手动处理一次。

覆盖安装会丢数据吗？＋

Windows 不会。数据保存在安装目录之外，覆盖安装不会碰它，新版本启动后继续使用同一份数据。如果你把数据放在了自定义位置而新版本没有认出来，可以在应用的设置 → 存储里用「设置数据路径」重新指向它——这个操作只改指针，不会复制或删除任何文件。Android 从 v1.6.0 升级需要卸载重装，卸载会清空应用内数据，所以一定要先导出；装上 v1.6.3 或更新的版本之后，更新都是覆盖安装，不会丢数据。

Android 为什么要卸载重装？＋

旧的签名密钥在开发电脑重置系统时丢失，已经无法找回，新版只能用新签名发布。我们等了两个版本，最终决定不再让 Android 用户继续留在有问题的 v1.6.0 上（例如世界书无法注入），所以在 v1.6.3 提供导出后重装的迁移方式。给你带来麻烦，非常抱歉。
