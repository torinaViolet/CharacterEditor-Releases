角色卡脚本 API

在角色卡中编写 JavaScript 脚本或 HTML/CSS/JS 消息组件，通过生命周期事件和消息宏扩展 RP 会话。本文对应 Character Editor v1.7 系列的卡内脚本运行时。

本页内容 快速开始 执行时机与授权 ce 对象 sdk 接口 消息宏与组件 运行边界

快速开始

打开角色卡编辑页的「角色卡脚本」，新建脚本，填写代码并选择执行时机和权限。保存后启用脚本，再对当前版本进行本机授权。修改脚本后需要重新授权。

// 选择「会话开始」，勾选「读取变量」「修改消息与会话变量」
ce.declareSession("hp", 100);
ce.var.turn = 0;
return "会话已初始化";

默认模式把编辑器内容当作异步 JavaScript 函数体运行，可以直接使用 await。若启用「ES 模块」，请导出 run 函数；消息宏也可以调用其他导出的函数。

// ES 模块模式
export async function run(name = "旅人") {
  return `你好，${name}`;
}

执行时机与授权

事件发生时间
sessionStart新 RP 会话首次发送消息时执行。旧会话不会补跑；只有此事件可以注册会话共享变量。
beforeGenerate每次生成回复前执行。
afterGenerate生成回复后执行。
message通过 script 消息宏调用；需要另行开启「允许消息宏调用」。

运行时提供 event（当前事件名）、args（消息宏的位置参数数组）、ce 和 sdk。权限需要在脚本中勾选，并由用户为此设备上的当前脚本版本授权。

权限用途
context.read读取 ce.ctx 对话上下文。
state.read读取 ce.var、ce.session 和 ce.app。
state.write修改 ce.var、已注册的 ce.session 变量；需同时勾选 state.read。
notes.read / notes.write列出、读取或写入当前 RP 会话笔记；写入权限也需要读取权限。
knowledge.read查阅当前角色卡启用的按需世界书条目。

ce 对象

成员说明
ce.ctx只读的角色与消息上下文，例如 ce.ctx.char。
ce.var当前剧情分支变量。普通赋值和 delete 会记录变更。
ce.session本 RP 会话的共享变量；只能写入已由会话开始脚本注册的名称。
ce.app只读的应用变量，并提供 time() 与 random()。
ce.declareSession(name, initial)仅在 sessionStart 注册共享变量，首次注册时设置初始值。

变量值必须是可序列化的 JSON 值。读取到的对象是只读快照；修改嵌套值时，请构造新对象并重新赋给变量。删除变量请使用 delete ce.var.name 或 delete ce.session.name。

sdk 接口

桥接调用都是异步的，按所选权限检查。笔记的 scope 为 node（跟随剧情分支）或 session（会话共享）。

方法作用
sdk.notes.list({ query, offset, limit })分页列出当前会话笔记索引。
sdk.notes.read(scope, path)读取笔记正文与 revision；不存在时返回 null。
sdk.notes.write(note)创建或更新笔记。传入 scope、path、title、text、可选 summary，以及 expectedRevision；新建时该值为 null。
sdk.notes.delete(scope, path, expectedRevision)按版本删除笔记。
sdk.knowledge.list({ query, offset, limit })搜索当前角色卡启用的按需世界书索引。
sdk.knowledge.read(id, { revision, offset })读取条目正文，每次最多返回 12000 字符，并给出 next_offset。
const current = await sdk.notes.read("node", "npc.md");
await sdk.notes.write({
  scope: "node",
  path: "npc.md",
  title: "NPC 线索",
  summary: "已确认的背景",
  text: "记录正文",
  expectedRevision: current?.revision ?? null,
});

const page = await sdk.knowledge.list({ query: "城镇" });
if (page.items.length) {
  const entry = await sdk.knowledge.read(page.items[0].id);
  return entry.content;
}

笔记写入和删除采用版本检查；若其他操作已改动同一笔记，会返回冲突错误。脚本执行失败或撤权时，本次暂存的状态和笔记修改会被丢弃。

消息宏与组件

脚本开启「允许消息宏调用」并授权后，可在新提交的消息里使用脚本名称或唯一资源 ID。函数体模式仅有 run；ES 模块可调用其他导出函数。参数在代码中通过 args 或导出函数的位置参数读取。

{{script::脚本名称::run::参数}}
{{!script::脚本名称::run::参数}}  // 执行但不输出

HTML/CSS/JS 消息组件通过 ui 宏插入，组件内可读取生成消息时的 ce 快照和 args，并操作自己的 DOM。组件不能直接修改剧情状态；需要写入状态时由脚本宏完成。

{{ui::组件名称::参数}}

脚本和组件宏只在消息首次提交时处理；重新渲染历史消息不会再次执行。代码围栏、行内代码和转义的宏示例不会执行。重名时请改用唯一资源 ID。

运行边界

  • 脚本在隔离运行时执行，不提供任意文件系统、密钥、长期记忆或其他角色卡访问接口。
  • 只可查阅当前角色卡启用的按需世界书；自动注入条目不会因此变成脚本可读。
  • 单张卡最多挂载 30 个脚本；单条消息最多调用 32 次脚本或组件。
  • 脚本有执行超时和输出长度限制；会话切换、撤权或失败会取消本次执行。
